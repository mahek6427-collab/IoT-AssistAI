Merge Sort

Merge Sort is a Divide and Conquer algorithm. It divides the input array into two halves, calls itself for the two halves, and then merges the two sorted halves.

Metric Complexity
Best Time Ω(n log n)
Average Time Θ(n log n)
Worst Time O(n log n)
Space O(n)
C++ Implementation 
void merge(int arr[], int l, int m, int r) {
    int n1 = m - l + 1;
    int n2 = r - m;
    int L[n1], R[n2];

    for (int i = 0; i < n1; i++) L[i] = arr[l + i];
    for (int j = 0; j < n2; j++) R[j] = arr[m + 1 + j];

    int i = 0, j = 0, k = l;
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) {
            arr[k] = L[i]; i++;
        } else {
            arr[k] = R[j]; j++;
        }
        k++;
    }
}

AVL Trees

A self-balancing binary search tree where the height of two child subtrees of any node differs by at most one.

  • Search: O(log n)
  • Insert: O(log n)
  • Delete: O(log n)
// AVL Tree Node Implementation
struct Node {
    int key;
    struct Node *left;
    struct Node *right;
    int height;
};

int getBalance(struct Node *N) {
    if (N == NULL) return 0;
    return height(N->left) - height(N->right);
}

Graph Theory & Representation

Hamiltonian Paths & Cycles

A Hamiltonian path visits every vertex exactly once. A Hamiltonian cycle is a Hamiltonian path that is a cycle. Finding these is generally NP-complete.

Matrix Representations

Graphs are computationally represented using matrices or lists. An Adjacency Matrix is a 2D array of size V x V where V is the number of vertices.

Adjacency Matrix Example

  A B C D
A 0 1 0 1
B 1 0 1 0
C 0 1 0 1
D 1 0 1 0

Space Complexity: O(V²). Fast to query edge existence: O(1).

// C++ Adjacency Matrix Setup 
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int V = 4;
    // Initialize a V x V matrix with zeros
    vector<vector<int>> adjMatrix(V, vector<int>(V, 0));

    // Add edge between 0 and 1
    adjMatrix[0][1] = 1;
    adjMatrix[1][0] = 1; // Undirected
    
    return 0;
}

Tree Data Structures

Advanced hierarchical structures essential for databases and fast lookups.

AVL Trees

A self-balancing binary search tree. In an AVL tree, the heights of the two child subtrees of any node differ by at most one. If at any time they differ by more than one, rebalancing (rotations) is done to restore this property.

  • Search: O(log n)
  • Insert: O(log n)
  • Delete: O(log n)

B-Trees

A self-balancing tree data structure that maintains sorted data and allows searches, sequential access, insertions, and deletions in logarithmic time. Optimized for systems that read and write large blocks of data.

  • Widely used in Databases
  • Widely used in File Systems
  • Minimizes disk I/O operations

Graph Theory

Hamiltonian Paths & Cycles

A Hamiltonian path (or traceable path) is a path in an undirected or directed graph that visits every vertex exactly once. A Hamiltonian cycle is a Hamiltonian path that is a cycle (the first and last vertices are connected).

Complexity & Nature

Determining whether such paths and cycles exist in graphs is the Hamiltonian path problem, which is NP-complete.

Common approaches to solve or approximate this include Backtracking, Dynamic Programming (Held-Karp algorithm with complexity O(n² 2ⁿ)), and various heuristics.
